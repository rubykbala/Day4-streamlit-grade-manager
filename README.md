# Streamlit Student Grade Manager

Week 1 Day 4 assignment. A Streamlit version of the Day 2 grade manager.

## Output

![App output](output.png)

## Features
- Add a student with a name and a mark (0 to 100)
- Results table with name, mark and grade
- Class average, highest and lowest marks
- Students are kept in st.session_state so they survive Streamlit reruns

## Run it
streamlit run grade_app.py
